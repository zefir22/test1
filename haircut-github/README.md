# Срез — запись на стрижку

1. Распакуйте архив на хостинге с Node.js 24 или новее.
2. Задайте переменные окружения NODE_ENV=production и HAIRCUT_PASSWORD со своим паролем для журнала.
3. Укажите в HAIRCUT_DB_PATH абсолютный путь к файлу SQLite в постоянном диске хостинга. Каталог должен существовать и быть доступен приложению на запись. Используйте один экземпляр приложения.
4. Запустите npm start. Если хостинг задаёт PORT, сайт использует этот порт.
5. Подключите HTTPS через настройки хостинга. Откройте выданный адрес и проверьте форму и вкладку «Журнал».

При локальном запуске без переменных сайт доступен по адресу http://127.0.0.1:8765/. Пароль выводится в терминале, база создаётся рядом с server.mjs.
